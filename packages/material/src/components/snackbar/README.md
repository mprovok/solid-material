The `<MaterialSnackbarContainer>` component is automatically rendered by the `<MaterialNavigationLayout>` component.

The horizontal position can be controlled using the `snackbarAlignment` prop:

- `start`

- `center`

The snackbar is always vertically positioned above the navigation bar and FAB.

The tooltip of the close button in all snackbars can be specified with the `snackbarCloseTitle` prop.
