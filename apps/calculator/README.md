# A calculator web app using Solid Material

This is a small app demonstrating the use of Solid Material, a component
library implementing the Material 3 Expressive spec using SolidJS.

It tries to imitate the basic calculator app found in Android, but with a few differences:

- Buttons are part of a standard button group, thus they expand a bit when pressed
- The "Inv" and "Deg" buttons are toggle buttons

It is missing the following features:

- Automatic insertion of the thousands separator
- Horizontal scrolling of input and output
- Cursor
- Cut/copy/paste and MS/MR/M+/M- functionality
- History
